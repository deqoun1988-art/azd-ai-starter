## The `src` folder is a placeholder for your application

The current application is just a static frontend page used to run the tests. You can completely remove the `app` folder or replace it with your own application.

Please place your application code in this folder. For detailed guidance on folder structure, go [here](https://github.com/Azure-Samples/azd-template-artifacts/blob/main/docs/structure-samples/structure-samples.md)
